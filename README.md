# 📝 Blogspot – Personal Lifestyle Blog Website
 
A clean, modern, and responsive personal blog website built using **only HTML and CSS**. The site belongs to a fictional lifestyle blogger, "Sarah Smith", and showcases blog posts, a photo gallery, a newsletter section, and a contact footer.
 
---
 
## 🚀 Live Demo
 
🔗 [Click here to view the live website](https://blogspotwebo.vercel.app/)

---

## ✨ Features
 
- **Sticky navigation bar** with links to Home, Blogs, About Me, and Contact
- **Hero section** with a full-width banner image, dark overlay, and the blogger's name and tagline
- **Blog cards** with category label, title, short description, "Read More" link, views, and likes count
- **Author avatars** displayed beside the "My Blog" heading
- **Newsletter subscription section** with a styled email input and subscribe button
- **Image gallery** laid out in a clean grid with rounded corners
- **Footer** with contact details, social media icons, and quick links
- Built with **no frameworks and no JavaScript** – just pure HTML and CSS
